# Modelling-Paracetamol-Production-in-a-Continuous-Environment
Paracetamol is often made in a batch fashion. Continuous production has been shown to be more economical, but adoption has been slower due to regulation. This simulation is a case for the adoption of continuous production of paracetamol.
# Folder Descriptions
1. **Output**
   This contains the CSV files of the different reactor configurations and experiments.
2. **Plots**
   This contains the various plots that use the values from the Output folder to understand the performance of each reactor
3. **R code**
   This contains the code run that led to the creation of the Output folder, including for Batch reactor, PFR, and CSTR
